# 搜索

按关键词查询单曲，返回曲目 ID、歌名、时长等信息。

```bash
vncmd search <关键词> [-c 数量] [-o 偏移] [-j]
```

| 参数 | 简写 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--count N` | `-c` | 面板 `10` | 最多返回条数，1-100 |
| `--offset N` | `-o` | `0` | 分页偏移，从 0 计 |
| `--json` | `-j` | 关 | 以 JSON 输出并退出 |

search 功能在大于 100 宽度的终端会表现更好。  
因为涉及到表格，在过窄的终端窗口中，数据会频繁折行而影响阅读。

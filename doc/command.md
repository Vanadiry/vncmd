# 命令

```bash
python vnemd.py <type>
```

 `type` 为 `search` 是搜索模式，能够按关键词查询单曲，并返回曲目ID、歌名、时长等信息。  
 `type` 为 `song/playlist/album` 对应`单曲/歌单/专辑`，可以预览和下载。  
 `type` 为 `tracker` 是追踪模式，可以管理追踪列表、同步远端变更并批量下载。

## search

```bash
python vnemd.py search <关键词> [-n 数量] [--offset 偏移]
```

| 参数           | 简写   | 说明         |
| ------------ | ---- | ---------- |
| `--limit N`  | `-n` | 返回数量，默认 30 |
| `--offset N` | `/`  | 分页偏移       |

## 下载模式通用

下面的参数控制下载时的行为，在 `song/playlist/album/tracker` 三个模式通用。

| 参数           | 简写   | 说明                      |
| ------------ | ---- | ----------------------- |
| `--download` | `-d` | 下载                      |
| `--quality`  | `-q` | 临时覆盖音质（128/192/320/999） |
| `--output`   | `-o` | 临时覆盖输出目录                |

## song

```bash
python vnemd.py song <ID> [-l] [-u] [-d] [-q 音质] [-o 目录]
```

将会预览指定音乐的信息（标题、歌手、专辑、封面链接、时长）。  
加入歌词相关参数，能够预览歌词。

| 参数         | 简写   | 说明           |
| ---------- | ---- | ------------ |
| `--lyrics` | `-l` | 显示原文歌词流      |
| `--tlyric` | `/`  | 显示翻译歌词流      |
| `--url`    | `-u` | 检查流 URL 是否可用 |

## playlist/album

```bash
# 歌单
python vnemd.py playlist <ID> [-n 数量] [-d] [-q 音质] [-o 目录]
# 专辑
python vnemd.py album <ID> [-n 数量] [-d] [-q 音质] [-o 目录]
```

将会以表格形式预览歌单/专辑中的曲目。

| 参数        | 简写   | 默认   | 说明                |
| --------- | ---- | ---- | ----------------- |
| `--limit` | `-n` | `10` | 预览条数 / 下载曲数（默认全部） |

## tracker

```bash
python vnemd.py tracker <名称> [-f | --fetch-auto] [-d] [--diff] [-q 音质] [-o 目录]
```

| 参数 | 简写 | 说明 |
| --- | --- | --- |
| `--fetch` | `-f` | 拉取，交互式解决冲突 |
| `--fetch-auto` | `/` | 自动同步，镜像上游 |
| `--diff` | `/` | 下载自上次拉取以来新增的曲目，需要同时传入 `-d` 才会下载 |

### 冲突处理

`-f` 模式下，拉取完成后会列出三类变更：

- 新增：远端列表中存在，但本地列表中不存在。
- 移除：远端列表中不存在，但本地列表中存在。
- 变更：ID 相同，但曲目名称不同。

`--fetch-auto` 模式则会自动接受全部变更，就是直接镜像上游了。最后会输出变更列表。

每次写入缓存前，会自动备份列表，如需回滚可手动覆盖。

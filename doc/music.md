# 单曲/歌单/专辑

`song`、`playlist`、`album` 对应单曲、歌单、专辑，可以预览和下载。

## 通用参数

以下参数在三个模式中通用。

| 参数 | 简写 | 说明 |
| --- | --- | --- |
| `--download` | `-d` | 下载 |

## song

```bash
vncmd song <ID> [-l] [--tlyric] [-u] [-d]
```

预览指定曲目的信息（标题、歌手、专辑、封面链接、时长）。

| 参数 | 简写 | 说明 |
| --- | --- | --- |
| `--lyrics` | `-l` | 显示原文歌词 |
| `--tlyric` | `/` | 显示翻译歌词 |
| `--dlink` | `-u` | 显示下载链接与音质、费用等详情，取不到链接时也会说明原因 |

## playlist / album

```bash
# 歌单
vncmd playlist <ID> [-n 数量] [--offset 序号] [--json] [-d]
# 专辑
vncmd album <ID> [-n 数量] [--offset 序号] [--json] [-d]
```

以表格预览歌单或专辑中的曲目。若歌单中存在已下架曲目，会单独列出提醒。

| 参数 | 简写 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--limit` | `-n` | 面板 `10` | 最多处理曲目数，面板、`--json` 与下载共用它 |
| `--offset` | `/` | `0` | 起始序号，从 0 计 |
| `--json` | `/` | 关 | 以 JSON 输出结果并退出，供脚本读取 |

下载时支持并发，可在配置 `[download]` 中的 `concurrency` 调整同时下载数，默认 4。

# 单曲/歌单/专辑

`song`、`playlist`、`album` 对应单曲、歌单、专辑，可以预览和下载。

## 通用参数

以下参数在三个模式中通用，`-q`/`-o`/`--dry-run` 均需配合 `-d` 传入。

| 参数 | 简写 | 说明 |
| --- | --- | --- |
| `--download` | `-d` | 下载 |
| `--quality` | `-q` | 临时覆盖音质（128 / 192 / 320 / 999） |
| `--output` | `-o` | 临时覆盖输出目录 |
| `--dry-run` | `/` | 仅预览要下载的内容，不实际下载 |

## song

```bash
vncmd song <ID> [-l] [--tlyric] [-u] [-d] [-q 音质] [-o 目录]
```

预览指定曲目的信息（标题、歌手、专辑、封面链接、时长）。

| 参数 | 简写 | 说明 |
| --- | --- | --- |
| `--lyrics` | `-l` | 显示原文歌词 |
| `--tlyric` | `/` | 显示翻译歌词 |
| `--url` | `-u` | 检查流 URL 是否可用 |

## playlist / album

```bash
# 歌单
vncmd playlist <ID> [-n 数量] [-d] [-q 音质] [-o 目录]
# 专辑
vncmd album <ID> [-n 数量] [-d] [-q 音质] [-o 目录]
```

以表格预览歌单或专辑中的曲目。若歌单中存在已下架曲目，会单独列出提醒。

| 参数 | 简写 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--limit` | `-n` | `10` | 预览条数（仅控制展示，API 始终拉取全量）；下载时默认全量 |

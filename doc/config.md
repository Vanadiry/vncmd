# 配置

配置文件存放在 `config/config.toml`。
Cookie 存放在 `config/cookie`，纯文本。

启动时会校验配置，缺少项会报错退出。

## download

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `dir` | `downloads` | 下载目录。<br>支持 `~` 和相对路径 |
| `quality` | `999` | 音质。<br>128/192/320 为对应 kbps，999 为无损。 |
| `filename_format` | `10` | 文件名格式化。<br>`10`: 歌名 - 歌手｜`01`: 歌手 - 歌名｜`1`: 仅歌名 |
| `download_content` | `012` | 要下载的内容（可组合或单选，例如`01`）。<br>`0`: 歌曲｜`1`: 歌词｜`2`: 封面 |
| `embed_lyrics_mode` | `2` | 嵌入音频的歌词模式。<br>`0`: 交错｜`1`=合并｜`2`=原始（仅原文流） |
| `save_lyrics_mode` | `0` | 独立歌词文件模式。<br>`0`: 交错｜`1`: 合并｜`2`: 原始（可能有多个流） |
| `embed_cover_quality` | `1` | 嵌入封面。<br>`0`: 原图｜`1`: 最大500px 的 JPEG |
| `save_cover_quality` | `0` | 独立封面文件。<br>`0`: 原图｜`1`: 最大500px 的 JPEG |

### 封面质量（cover_quality）

如果要把封面嵌入音频，适合使用 `1` 模式。

若设置为 `1`，则任一边大于 `500px` 的封面，会被缩放到 `500px` 以内。  
所有格式会被转换为 JPEG，透明 Alpha 通道会被替换为白色。  
转换时，质量设置为 `60`，以确保文件体积小。

## 歌词模式（lyrics_mode）

一些歌有好几个歌词流，特别是外语歌。通常是原文和翻译两个流。  
因此设置了歌词模式，方便处理歌词。

交错模式 `0`：  
原文和译文两个流，逐行交错插入。  
匹配方式为时间戳，有 `300ms` 容差（两句歌词相差 `300ms` 会被视作同一句）。

合并模式 `1`：  
直接将译文流拼接到原文流下面。

原始模式 `2`：
在嵌入音频时，只会嵌入原文流。  
在下载歌词时，会分别下载所有流。原文流文件名和音频一样，其他流依次加上 `.2`、`.3`的后缀。

## cache

如果你不知道这是什么意思，就不要动。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 是否启用缓存 |
| `dir` | `cache` | 缓存目录（相对路径） |

## tracker

追踪列表配置存放在 `tracker/<名称>/settings.toml`，每个追踪列表一个文件夹。  
新建一个追踪列表时候，会写入一份空配置，手动编辑即可。

| 键 | 类型 | 说明 |
| --- | --- | --- |
| `tracker.description` | 字符串 | 描述，仅展示 |
| `sources[].type` | 字符串 | 来源类型：`song/playlist/album` |
| `sources[].ids` | 整数数组 | 该类型下的 ID 列表，可一次指定多个 |

程序拉取时会按 `[[sources]]` 逐条处理，每个来源中的 `ids` 会被遍历。  
同一首歌出现在多个来源时，缓存中会记录 `at` 字段标记所有来源。

追踪列表的名称为文件夹名（`tracker/` 下的子目录名），仅允许大小写字母、数字、短横线和下划线。

# 配置

配置文件存放在 `~/.vSoft/vncmd/config.toml`。
Cookie 存放在 `~/.vSoft/vncmd/cookie`，纯文本。

启动时会校验配置，缺少项会报错退出。若配置不存在，会自动创建。  
同一时间只能运行一个 vncmd 实例。

程序已经预设了足够正常使用的配置，手动修改配置之前，请确保你了解每个配置的用途。

## [download]

### dir

下载目录。默认 `""`（空）。

支持绝对路径和基于 `~/.vSoft/vncmd` 的相对路径。留空则使用 `~/Downloads/vncmd-dl/`。

### filename_format

文件名格式。默认 `"10"`。

- `"10"`：歌名 - 歌手
- `"01"`：歌手 - 歌名
- `"1"`：仅歌名

### content

下载内容。默认 `"012"`。

- `"0"`：音频
- `"1"`：歌词
- `"2"`：封面

可以任意组合，例如 `"12"` 表示只下载歌词和封面，`"0"` 表示只下载音频。

### concurrency

并发下载数。默认 `4`。

范围 1-16，过高可能触发风控。

### check

下载后做全量解码校验。默认 `true`。

开启后，会用 ffmpeg/flac 对音频完整解码，可以查出文件截断、容器损坏等不易发现的问题。  
需要系统中装有 ffmpeg/flac 库。若部分/全部未安装，则会跳过对应校验。

### downloader

下载功能的实现方式。默认 `"builtin"`。

- `"builtin"`：使用内建下载实现
- `"curl"`：调用系统 curl

### curl_arg

追加给 curl 的参数。默认 `""`。

仅在 `downloader` 为 `"curl"` 时生效。  
按 shell 的切分规则解析，可以写多个参数。

## [download.song]

### quality

音质。默认 `"999"`。

- `"128"`：128 kbps
- `"192"`：192 kbps
- `"320"`：320 kbps
- `"999"`：最高可用

### parse_credits

从歌词解析并嵌入更多元数据。默认 `false`。
（受到 `credit_scan_lines` 的行数限制）

启用（`true`）后，将自动从歌词头部解析 credit 数据，按对应格式的标准嵌入元数据。  
目前支持：作曲、作词、编曲、制作人、混音、录音、指挥（包括简中/繁中/部分英文）。

另外，以下一些连写情况会被特殊处理：

- `混音/母带`：记录混音，母带保留。
- `作/編曲`、`作编曲`、`作曲/编曲`等：记录作曲和编曲

## [download.lyric]

### embed_mode

嵌入到音频文件中的歌词格式。默认 `"2"`。

- `"0"`（交错）：原文和译文逐行交错。匹配依赖时间戳，相差 300ms 以内的两句视为同一句。
- `"1"`（合并）：译文流直接拼接在原文流下方。
- `"2"`（原始）：仅嵌入原文流。

### save_mode

独立 lrc 文件的歌词格式。默认 `"0"`。

与 `embed_mode` 含义相同。  
模式 `"2"`（原始）时，会生成多个文件：原文为 `.lrc`，译文为 `.2.lrc` 等。

### auto_trim

裁剪无用歌词数据。默认 `false`。
（受到 `credit_scan_lines` 的行数限制）

启用后，会删除歌词中的以下内容：

- 含“纯音乐，请欣赏”的行
- 值为“无”的 credit 行，例如 `作词 : 无`
- 角色名为“歌词翻译”或“歌詞翻譯”的行

若同时启用 `parse_credits`，还会删除已被嵌入元数据的行。

如果裁剪完毕后，歌词中没有任何数据，将丢弃歌词。

### credit_scan_lines

检查 credit 数据的行数。默认 `10`。在启用 `auto_trim` 或/和 `parse_credits` 时生效。

检测 parse_credits 与/或 auto_trim 中记录的要删除的行，只扫描歌词前 N 行。  
这能避免将正文中出现的角色关键词误判为 credit。

## [download.cover]

### embed_quality

嵌入音频的封面质量。默认 `"1"`。

- `"0"`：原图，不做任何处理。
- `"1"`：等比缩放至 500px 以内（小图忽略），转换为 JPEG，透明通道替换为白色背景，质量自适应（60–85）。

### save_quality

独立封面质量。默认 `"0"`。规则同 `embed_quality`。

## [cache]

### enabled

本地缓存。默认 `true`。

关闭后，歌词、曲目详情每次都会从 API 拉取，更慢但更实时。

### dir

缓存目录。默认 `"cache"`。

支持绝对路径和基于 `~/.vSoft/vncmd` 的相对路径。

### ttl

缓存有效期，单位为天。默认 `3`。

`0` 表示永不过期。

## [display]

### artist_color

艺术家按各自代表色着色。默认 `true`。

将展示的艺术家名字，按照 vncmd 预设的颜色对照表着色。  
目前收录类型有 Vocaloid、世界计划、VTuber等。
